# Identidad visual — Así los Dentistas Dijeron

Carpeta para incorporar los tres recursos gráficos oficiales de la aplicación.

Sube aquí los archivos PNG con fondo transparente y conserva estos nombres:

- `logo.png` — logotipo completo con tucán y nombre de la aplicación.
- `icono.png` — icono de la aplicación, solo el tucán y sin texto.
- `slogan.png` — frase o eslogan independiente, sin el tucán.

## Indicaciones

- Formato recomendado: PNG con transparencia real (canal alfa), no una cuadrícula dibujada como fondo.
- No combines las tres imágenes en un solo archivo.
- Mantén cada recurso como archivo independiente.
- Esta carpeta está dentro de los recursos Android (`app/src/main/assets`) para facilitar su integración posterior en la aplicación.

Cuando estén cargados, avisa con: «ya subí las tres imágenes».
