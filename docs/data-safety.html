RESUMEN PARA PUBLICACIÓN

Seguridad de datos

Estado correspondiente a la versión actual del proyecto · 17 de septiembre de 2026.

Resumen actual: la app funciona localmente, no requiere cuenta, no incluye anuncios y no declara permisos de ubicación, cámara, contactos o micrófono.

Recopilación por el desarrollador

  • Datos personales: no recopilados por servidores del proyecto.
  • Actividad de la app: no se envía al desarrollador.
  • Ubicación: no recopilada.
  • Fotos, videos y archivos: no recopilados.
  • Contactos: no recopilados.
  • Información financiera: no recopilada.
  • Identificadores de dispositivo/publicidad: no usados por el proyecto en la versión actual.

Datos almacenados localmente

La aplicación puede guardar preferencias del juego —por ejemplo nombres de equipos y selecciones visuales— únicamente en el dispositivo. Esa información no se transmite al desarrollador.

Permisos Android actuales

El manifiesto actual no solicita permisos sensibles. Esta página deberá revisarse si una futura versión añade reconocimiento de voz, servicios en línea, analítica, publicidad, cuentas o almacenamiento remoto.

Reconocimiento de voz futuro

La función de voz todavía no forma parte de la declaración actual. Antes de publicarla se documentará el permiso de micrófono y el proveedor de reconocimiento utilizado, y se actualizarán esta página, la política de privacidad y la sección de Seguridad de los datos de Google Play.

Sitio web

La web oficial está alojada en GitHub Pages. GitHub puede tratar datos técnicos como la dirección IP para seguridad de su servicio. Consulte la Política de privacidad para más detalles.
