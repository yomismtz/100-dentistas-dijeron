RESUMEN PARA PUBLICACIÓN

Seguridad de datos

Estado correspondiente a la versión 3.0.1 beta del proyecto · 19 de septiembre de 2026.

Resumen: la app funciona principalmente de forma local, no requiere cuenta, no incluye anuncios ni analítica propia y no transmite partidas a un servidor del proyecto. La voz es opcional y se procesa mediante el servicio de reconocimiento instalado en Android.

Recopilación por el desarrollador

  • Datos personales: no recopilados por servidores del proyecto.
  • Actividad de la app: no se envía al desarrollador.
  • Ubicación: no recopilada.
  • Fotos, videos y archivos: no recopilados.
  • Contactos: no recopilados.
  • Información financiera: no recopilada.
  • Identificadores de dispositivo/publicidad: no usados por el proyecto.

Datos almacenados localmente

La aplicación puede guardar nombres de equipos, personajes, ajustes, historial de preguntas, preguntas personalizadas, autoguardados, sesiones y reportes académicos, paquetes de clase, torneos/campeonatos, pretest/postest, metadatos editoriales y, si el docente lo decide, imágenes clínicas seleccionadas explícitamente desde el selector de documentos de Android. Esa información permanece en el dispositivo y no se transmite al desarrollador.

Reconocimiento de voz

Al tocar el botón de micrófono, la aplicación invoca el servicio de reconocimiento de voz instalado en Android. 100 Dentistas Dijeron no almacena grabaciones de audio. El servicio de reconocimiento puede procesar la voz localmente o mediante los servidores de su proveedor, según la configuración del dispositivo y las políticas del proveedor. La app recibe el texto reconocido y lo compara localmente con las respuestas del tablero.

Permisos y selectores Android

La app no solicita permisos de ubicación, cámara, contactos ni acceso general al almacenamiento. Declara INTERNET para el servidor HTTP/WebSocket del modo aula dentro de la red Wi‑Fi/hotspot local. Para importar una imagen o exportar CSV/Excel/PNG utiliza selectores de documentos del sistema: el usuario elige explícitamente el archivo de entrada o la ubicación de salida. La experiencia de voz se realiza mediante el reconocedor instalado en Android y puede depender de sus permisos y ajustes.

Modo aula offline

Los pulsadores, el control docente y las respuestas individuales pueden comunicarse por la misma red local sin salida a Internet. El estado público para alumnos excluye respuestas correctas y referencias privadas; el control docente requiere un PIN local y las referencias se comparten solo cuando el docente las desbloquea.

Investigación y exportaciones

El modo investigación es opcional y utiliza códigos de sesión anónimos; no requiere nombres individuales. Los resultados permanecen locales hasta que el docente decide exportarlos. Los archivos CSV, compatibles con Excel y las tarjetas PNG se guardan solo en la ubicación elegida mediante Android.

Imágenes clínicas

La importación de imágenes es opcional. Solo se recibe la imagen que el docente selecciona; se procesa y guarda localmente. El proyecto no la recopila ni la transmite a servidores propios. El docente es responsable de usar material autorizado y sin identificadores de pacientes.

Enlaces científicos

El modo docente puede abrir fuentes científicas en el navegador externo. El tratamiento de datos en esos sitios se rige por las políticas de cada proveedor.

Sitio web

La web oficial está alojada en GitHub Pages. GitHub puede tratar datos técnicos como la dirección IP para seguridad de su servicio. Consulte la Política de privacidad para más detalles.
