## Criterio de uso

- H01–H25 y H31–H35 son las fuentes principales para hechos científicos o históricos.
- H26–H30 se reservan para cultura popular y ficción.
- H25 es especialmente importante para las preguntas sobre tradiciones de dientes de leche: la revisión sistemática identificó siete grandes temas de disposición de dientes exfoliados.
- Las atribuciones históricas discutibles no se redactan como descubrimientos absolutos.
- Los puntos 40/25/15/12/8 son pesos internos para el formato “100 dentistas dijeron”; no son resultados de una encuesta poblacional.
