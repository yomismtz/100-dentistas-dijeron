DOCUMENTO DE PRIVACIDAD

Política de privacidad

Última actualización: 17 de septiembre de 2026.

Resumen: 100 Dentistas Dijeron funciona principalmente de forma local. No requiere cuentas, no integra publicidad ni analítica propia y no transmite partidas a un servidor del proyecto. La función opcional de voz utiliza el servicio de reconocimiento de voz instalado en Android; el proyecto no almacena grabaciones de audio.

1. Alcance

Esta política describe el tratamiento de información relacionado con la aplicación educativa 100 Dentistas Dijeron y con su sitio web oficial alojado mediante GitHub Pages.

2. Datos tratados por la aplicación Android

La aplicación no requiere registro ni cuenta de usuario. El juego puede guardar localmente en el dispositivo determinadas preferencias necesarias para la experiencia, como nombres de equipos, personajes seleccionados, ajustes de accesibilidad, historial reciente de preguntas y preguntas personalizadas creadas por el docente.

Estos datos se utilizan exclusivamente para mostrar y conservar la configuración del juego en el dispositivo. No se envían al desarrollador ni se utilizan para crear perfiles publicitarios.

3. Datos que la aplicación no recopila directamente

  • No recopila nombre legal, correo electrónico, teléfono ni dirección.
  • No recopila ubicación precisa o aproximada.
  • No accede a contactos, fotografías, cámara ni archivos personales.
  • No integra publicidad de terceros.
  • No integra herramientas propias de analítica o seguimiento de usuarios.
  • No transmite el contenido de las partidas a un servidor del proyecto.
  • No almacena grabaciones de voz.

4. Almacenamiento local y copias de seguridad

Las preferencias del juego y, cuando el docente lo elige, las preguntas personalizadas se almacenan localmente mediante mecanismos del componente web de Android. Dependiendo de la configuración del dispositivo, Android puede incluir determinados datos de la aplicación en sus mecanismos de copia de seguridad. El proyecto no opera un servidor propio para almacenar esos datos.

El usuario puede eliminar los datos locales desinstalando la aplicación o utilizando las opciones de almacenamiento de Android para borrar los datos de la app.

5. Aula offline y red local

La versión 2.7 incorpora un modo aula que puede crear un pequeño servidor HTTP únicamente en la red local del dispositivo para que los equipos usen sus teléfonos como pulsadores, envíen respuestas individuales y para que el docente use un control remoto protegido por PIN. Los dispositivos deben estar conectados a la misma red Wi‑Fi o hotspot.

Por este motivo la aplicación declara el permiso Android INTERNET, que Android utiliza también para comunicaciones por red local. El modo aula no requiere un servidor externo del proyecto ni necesita que la red tenga salida a Internet. Las partidas, respuestas y controles se procesan entre dispositivos de la red local y en el dispositivo anfitrión.

El estado público que consultan los equipos no incluye las respuestas correctas ni las fuentes/explicaciones privadas. El panel docente utiliza un PIN local generado al iniciar la app. Las referencias científicas locales se desbloquean únicamente cuando el docente decide compartirlas.

5. Reconocimiento de voz opcional

La aplicación ofrece un botón opcional para responder por voz. Al utilizarlo, la app solicita al sistema Android que abra el servicio de reconocimiento de voz instalado en el dispositivo. La aplicación 100 Dentistas Dijeron no captura ni conserva directamente el archivo de audio.

El servicio de reconocimiento seleccionado por el sistema puede procesar la voz localmente o enviarla a los servidores de su proveedor, según el dispositivo, la configuración, los paquetes de idioma instalados y las políticas de dicho proveedor. Ese procesamiento externo no es controlado por 100 Dentistas Dijeron.

Cuando el servicio termina, devuelve a la aplicación únicamente el texto reconocido. Ese texto se usa localmente para compararlo con las respuestas del tablero y no se envía a un servidor del proyecto ni se conserva como historial de voz.

La función de voz es opcional: todas las respuestas pueden escribirse manualmente. Si el dispositivo no dispone de un servicio de reconocimiento compatible, el juego sigue funcionando mediante texto y controles del docente.

10. Fuentes científicas y navegador externo

El modo docente puede abrir una fuente científica o institucional en el navegador externo del dispositivo. Al abrir un enlace, el tratamiento de datos queda sujeto a las políticas del navegador y del sitio visitado. La aplicación no incorpora rastreadores propios para estos enlaces.

7. Sitio web y GitHub Pages

El sitio oficial está alojado mediante GitHub Pages. El proyecto no instala cookies propias de publicidad ni incorpora analítica de terceros en este sitio. No obstante, GitHub puede registrar información técnica —incluida la dirección IP— por motivos de seguridad y puede utilizar cookies o tecnologías similares conforme a sus propias políticas.

Puede consultar la documentación de GitHub en GitHub Pages, su Declaración de Privacidad y su información sobre cookies.

8. Enlaces externos

El sitio y la app pueden incluir enlaces a GitHub, artículos académicos, guías clínicas u otros recursos. Al abandonar la aplicación o este sitio, el tratamiento de datos queda sujeto a las políticas del servicio externo correspondiente.

9. Uso educativo y menores de edad

La aplicación está diseñada con fines educativos. No está concebida para solicitar información personal a menores. Si se utiliza en un entorno escolar, se recomienda usar nombres de equipo, apodos no identificables o denominaciones genéricas en lugar de nombres completos de estudiantes.

10. Seguridad

La aplicación minimiza el tratamiento de datos al mantener la funcionalidad principal y las preferencias de juego de forma local. Ningún sistema puede garantizar seguridad absoluta, pero el proyecto busca limitar la exposición evitando cuentas, publicidad y servicios de seguimiento innecesarios.

11. Conservación y eliminación

El proyecto no conserva en servidores propios información de partidas, respuestas de voz, preferencias o preguntas personalizadas. Los datos almacenados localmente permanecen en el dispositivo hasta que la aplicación los sustituye, el usuario borra los datos o desinstala la aplicación.

12. Cambios en esta política

Esta política se actualizará cuando cambien de forma material las funciones de la aplicación, especialmente si en el futuro se incorporan servicios en línea, analítica, cuentas, publicidad o cualquier nuevo tratamiento de datos.

13. Contacto

Para preguntas, correcciones o solicitudes relacionadas con privacidad, puede abrir una incidencia pública en el repositorio del proyecto: GitHub Issues de 100 Dentistas Dijeron. Si la consulta contiene información personal o sensible, no la publique en una incidencia pública; solicite primero un canal privado.

14. Transparencia para Google Play

Esta página está destinada a servir como URL pública de política de privacidad de la aplicación. La información de la sección “Seguridad de los datos” de Google Play deberá mantenerse coherente con la versión concreta del APK publicada y con el comportamiento del servicio de reconocimiento de voz utilizado por Android.
