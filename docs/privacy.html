DOCUMENTO DE PRIVACIDAD

Política de privacidad

Última actualización: 13 de octubre de 2026.

Resumen: no se necesita una cuenta. Las preferencias y el estado de partida se guardan localmente. La app incluye permisos de micrófono, Internet y dispositivos cercanos para funciones opcionales; por eso no es correcto afirmar que nunca solicita permisos o que todas las funciones siempre operan sin conexión.

1. Alcance y responsable del proyecto

Esta política corresponde a la aplicación Android Así los dentistas lo dijeron (100 Dentistas Dijeron), paquete com.uam.cientodentistas, y al sitio informativo alojado en GitHub Pages. Para reportes técnicos se puede usar el rastreador de incidencias del proyecto. No publiques datos personales ni información clínica identificable en incidencias públicas.

2. Datos almacenados localmente

La aplicación puede guardar en el dispositivo preferencias, configuración, estado de la partida y progreso o estadísticas educativas para conservar la experiencia entre sesiones. Estos datos se almacenan localmente y el proyecto no ofrece sincronización de partidas con una cuenta o servidor propio en la versión descrita aquí.

3. Micrófono y reconocimiento de voz

La función opcional para responder por voz puede solicitar permiso de grabación de audio (RECORD_AUDIO) y usar el servicio de reconocimiento de voz disponible en Android o en el dispositivo. El audio se utiliza para reconocer la respuesta que el jugador dicta. Según el proveedor y la configuración del dispositivo, el reconocimiento puede procesarse en el dispositivo o transmitirse al proveedor externo. El proyecto no controla las prácticas de retención o tratamiento del proveedor. Si no deseas usar voz, responde escribiendo y no concedas el permiso de micrófono.

4. Conexión y dispositivos cercanos

El manifiesto Android declara permisos de Internet, Bluetooth (buscar, conectar y anunciar) y dispositivos Wi‑Fi cercanos, además de acceso al estado y cambio de Wi‑Fi. Estos permisos están relacionados con funciones de conexión o multijugador local previstas o disponibles en el proyecto. La presencia de un permiso no significa que se utilice continuamente. La versión del código debe revisarse antes de cada publicación para confirmar qué funciones de red están activas. El proyecto no afirma que esos permisos sean irrelevantes ni que la app no pueda comunicarse con servicios externos cuando una función compatible lo requiera.

5. Narración de texto a voz

La narradora usa el motor TTS disponible en Android. El texto se entrega al servicio de voz elegido en el dispositivo; sus condiciones y tratamiento técnico dependen del proveedor, idioma, configuración y si la voz se procesa localmente o en línea.

6. Datos que el proyecto recopila

El proyecto no anuncia una cuenta, publicidad ni analítica propia en la versión actual. No obstante, el sistema operativo, los servicios de reconocimiento/TTS y los servicios de alojamiento web pueden procesar datos técnicos conforme a sus propias políticas. No podemos asegurar que los proveedores del dispositivo o el alojamiento web no registren información técnica.

7. Datos que no debes introducir

No introduzcas nombres de pacientes, expedientes, radiografías identificables, datos de salud personales, contraseñas ni otra información confidencial. El juego no está diseñado como expediente clínico ni como repositorio de información de pacientes.

8. Menores de edad

La aplicación es educativa y no requiere crear una cuenta. Las personas responsables de menores deben supervisar el uso del reconocimiento de voz y los permisos del dispositivo. No se debe introducir información personal o clínica de menores.

9. Conservación y eliminación

Los datos locales pueden eliminarse desde los ajustes de Android borrando los datos de la aplicación o desinstalándola. Esto no elimina registros que un proveedor externo pudiera haber tratado según sus propias políticas. Los datos técnicos que GitHub procese al visitar el sitio se rigen por las políticas de GitHub.

10. Seguridad

Se aplican controles propios de la aplicación y del sistema Android, pero ningún software o transmisión puede garantizar seguridad absoluta. Mantén Android y la app actualizados, instala versiones de fuentes confiables y concede permisos solo cuando los necesites.

11. Cambios en esta política

Esta política puede cambiar si se incorporan cuentas, analítica, publicidad, sincronización, nuevas integraciones o permisos. La fecha de actualización se cambiará cuando se revise el documento. La ficha de Seguridad de los datos de Google Play debe coincidir con el APK/AAB que se distribuya.

12. Contacto y reportes

Para reportar problemas usa GitHub Issues. No adjuntes datos personales o clínicos sensibles.
