DOCUMENTO DE PRIVACIDAD

Política de privacidad

Última actualización: 17 de septiembre de 2026.

Resumen: la versión actual de la aplicación Android está diseñada para funcionar localmente. No crea cuentas, no integra publicidad, no utiliza analítica propia y actualmente no solicita permisos sensibles como ubicación, cámara o micrófono.

1. Alcance

Esta política describe el tratamiento de información relacionado con la aplicación educativa 100 Dentistas Dijeron y con su sitio web oficial alojado mediante GitHub Pages.

2. Datos tratados por la aplicación Android

En la versión actual, la aplicación no requiere registro ni cuenta de usuario. El juego puede guardar localmente en el dispositivo determinadas preferencias necesarias para la experiencia, como nombres de equipos, personajes seleccionados u otros ajustes del juego.

Estos datos se utilizan exclusivamente para mostrar y conservar la configuración del juego en el dispositivo. No se envían al desarrollador ni se utilizan para crear perfiles publicitarios.

3. Datos que la aplicación no recopila en la versión actual

  • No recopila nombre legal, correo electrónico, teléfono ni dirección.
  • No recopila ubicación precisa o aproximada.
  • No accede a contactos, fotografías, cámara ni archivos personales.
  • No integra publicidad de terceros.
  • No integra herramientas propias de analítica o seguimiento de usuarios.
  • No transmite el contenido de las partidas a un servidor del proyecto.

4. Almacenamiento local y copias de seguridad

Las preferencias del juego pueden almacenarse localmente mediante mecanismos del sistema o del componente web de Android. Dependiendo de la configuración del dispositivo, Android puede incluir determinados datos de la aplicación en sus mecanismos de copia de seguridad. El proyecto no opera un servidor propio para almacenar esos datos.

El usuario puede eliminar los datos locales desinstalando la aplicación o utilizando las opciones de almacenamiento de Android para borrar los datos de la app.

5. Reconocimiento de voz

La versión pública actual descrita por esta política no solicita permiso de micrófono. El proyecto contempla una futura función opcional de respuesta por voz. Si se incorpora, esta política y la declaración de seguridad de datos se actualizarán antes de publicar esa versión. La implementación deberá informar claramente qué servicio de reconocimiento procesa el audio, si el procesamiento ocurre en el dispositivo o mediante un proveedor externo, y qué datos se conservan.

6. Sitio web y GitHub Pages

El sitio oficial está alojado mediante GitHub Pages. El proyecto no instala cookies propias de publicidad ni incorpora analítica de terceros en este sitio. No obstante, GitHub puede registrar información técnica —incluida la dirección IP— por motivos de seguridad y puede utilizar cookies o tecnologías similares conforme a sus propias políticas.

Puede consultar la documentación de GitHub en GitHub Pages, su Declaración de Privacidad y su información sobre cookies.

7. Enlaces externos

El sitio puede incluir enlaces a GitHub, artículos académicos, guías clínicas u otros recursos. Al abandonar este sitio, el tratamiento de datos queda sujeto a las políticas del sitio externo correspondiente.

8. Uso educativo y menores de edad

La aplicación está diseñada con fines educativos. No está concebida para solicitar información personal a menores. Si se utiliza en un entorno escolar, se recomienda usar nombres de equipo, apodos no identificables o denominaciones genéricas en lugar de nombres completos de estudiantes.

Si una futura versión incorpora funciones que impliquen recopilación de datos personales de menores, la política será revisada antes de su publicación y se aplicarán los requisitos legales y de plataforma correspondientes.

9. Seguridad

La versión actual minimiza el tratamiento de datos al mantener la funcionalidad principal de forma local. Ningún sistema puede garantizar seguridad absoluta, pero el proyecto busca limitar la exposición evitando cuentas y servicios de seguimiento innecesarios.

10. Conservación y eliminación

El proyecto no conserva en servidores propios información de partidas o preferencias de usuarios. Los datos almacenados localmente permanecen en el dispositivo hasta que la aplicación los sustituye, el usuario borra los datos o desinstala la aplicación.

11. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, especialmente si se incorpora reconocimiento de voz, servicios en línea, analítica, cuentas o cualquier nuevo tratamiento de datos. La fecha de actualización se mostrará al inicio de este documento.

12. Contacto

Para preguntas, correcciones o solicitudes relacionadas con privacidad, puede abrir una incidencia pública en el repositorio del proyecto: GitHub Issues de 100 Dentistas Dijeron. Si la consulta contiene información personal o sensible, no la publique en una incidencia pública; solicite primero un canal privado.

13. Transparencia para Google Play

Esta página está destinada a servir como URL pública de política de privacidad de la aplicación. La información de la sección “Seguridad de los datos” de Google Play deberá mantenerse coherente con la versión concreta del APK publicada.
